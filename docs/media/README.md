# Media

Drop showcase assets here for the root README.

**Recommended format for an animated preview:** **GIF**

| Format | Use for GitHub README? | Notes |
|---|---|---|
| **GIF** | Best default | Embeds with `![](docs/media/showcase.gif)`. Widely supported. Keep it short and small (a few MB max). |
| Animated WebP | OK in many browsers | Smaller files, but weaker GitHub / old-client support than GIF. |
| MP4 / WebM | Prefer as a linked download or HTML `<video>` | Not as reliable as a plain markdown image embed. |

Suggested capture: short loop of the showcase scene (buttons, progress, icons, toasts, toggles, animations) at ~1280×720, 10–15s, then convert to GIF (e.g. ffmpeg / ScreenToGif / Kap).

Placeholder path used by the root README: [`showcase.gif`](./showcase.gif).
